# Kampung Kreator AI — V1.0

Paket website/PWA statis untuk program literasi digital, kreativitas, keamanan digital, dan produktivitas masyarakat.

## Isi
- Beranda
- AI Kreator berbasis prompt (tanpa API key)
- Tantangan 30 hari + localStorage
- Kuis Detektif Digital
- UMKM Digital
- Ruang Bhabinkamtibmas
- PWA/install ke layar utama
- Service worker

## Pasang gratis
Unggah seluruh isi folder ke hosting statis seperti GitHub Pages, Cloudflare Pages, Netlify, atau layanan sejenis. PWA/service worker membutuhkan HTTPS atau localhost.

## Kustomisasi
Edit nama petugas, desa, kontak resmi, dan agenda pada `index.html`.

## Keamanan
Jangan menaruh API key rahasia di JavaScript publik. Jangan memasukkan data pribadi sensitif atau data perkara ke AI publik.

## Pengembangan V2
Dashboard pengelola, akun/role, galeri karya, database, backend AI aman, papan prestasi, notifikasi, dan modul kegiatan.
